1. 页面骨架（每页固定这 5 行）

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>网页标题</title>
</head>
<body>
    页面内容
</body>
</html>
标签作用不写会怎样
<!DOCTYPE html>声明这是 HTML5，浏览器用标准模式渲染页面可能进入「怪异模式」，布局诡异
<html lang="zh-CN">根节点，lang 告诉浏览器/读屏软件这页是什么语言读屏软件会按英文念中文
<meta charset="UTF-8">字符编码，防中文乱码出现「锟斤拷」乱码
<meta viewport>手机端按设备宽度显示页面手机上网页缩成一团看不清
<title>浏览器标签页标题，也是搜索结果标题标签页显示文件名
<head>放「看不见的设置」：编码、标题、CSS 引入—
<body>放「看得见的内容」内容会跑到 head 里，页面空白
口诀：doctype 开门，html 大厅，head 后台，body 舞台。head 管设置，body 管内容。
你的例子：index.html / demo.html / todo.html 全是这个骨架，复制过来改 title 和 body 就行。

2. 文本标签全家桶

标签作用备注
<h1>~<h6>标题，h1 最大 h6 最小一个页面建议只有 1 个 h1
<p>段落段落之间默认有间距
<b>加粗（bold）只管显示，不强调语义
<strong>加粗且有语义（重要）能用 strong 就别用 b
<i>斜体（italic）也能表示「外来词」
<em>斜体且有语义（强调）—
<u>下划线（underline）—
<s>删除线（strike）表示「此内容作废」
<br>强制换行（break）自闭合标签，没有结束标签
<hr>水平分割线自闭合
<span>行内小容器（不换行）用来给一小段字加样式
<div>块级容器（独占一行）用来分块，几乎不写文字
&nbsp;一个不换行的空格& 开头叫「实体」
口诀：b 加粗、i 斜体、u 下划、s 删除、br 换行。
四个英文字母对应四个中文意思：b-bold、i-italic、u-underline、s-strike，记住英文首字母就不会错。
注意：HTML 里想显示 < > & 这三个符号本身，要写成 &lt; &gt; &amp;。

3. 链接与图片

写法含义举例
href="demo.html"站内相对链接（同文件夹）你 index.html 里的「最初页」
href="https://..."绝对链接（外站）你的原神链接
href="#"占位符：点了不跳，但有下划线样式你代码里的「有个链接」
href="#某id"页内锚点，跳到本页 id 位置配合 id="header" 使用
target="_blank"新标签页打开你的外链都加了这个
target="_self"当前页打开（默认）站内链接用这个
<img src="./tupian.images/qyf.jpg" alt="神图">
属性作用
src图片地址（相对路径用 ./ 或 ../）
alt图片加载失败/读屏时显示的替代文字（必写）
width/height图片显示尺寸
口诀：a 靠 href 出门，img 靠 src 进门；target="_blank" = 新开一扇窗。

4. 列表与表格

标签作用
<ul>无序列表（默认圆点）
<ol>有序列表（默认数字）
<li>列表项，必须放在 ul/ol 里面
<dl><dt><dd>描述列表（术语-解释）
<table><tr><th><td>表格：行 / 表头 / 单元格
colspan="2"横向合并 2 列
rowspan="2"纵向合并 2 行
你的 demo.html 有个小 bug：</ul> 和 <ol> 之间的换行多了一个，导致 <ol> 列表项被浏览器自动纠错修复。标准写法是 <ul>…</ul> 紧跟 <ol>…</ol>。
口诀：ul 无序、ol 有序、li 是「粒」；table 里面 tr 一行，th 表头，td 数据。

5. 表单（重点，你正在学的部分）

<form action="提交到哪个地址" method="get/post">
    <label for="pwd">密码：</label>
    <input type="password" id="pwd" name="pwd" placeholder="请输入密码">
    <select name="city">
        <option value="jx">江西</option>
    </select>
    <textarea name="txt" rows="4" cols="30"></textarea>
    <input type="submit" value="提交">
    <input type="reset" value="重置">
    <button type="button">普通按钮</button>
</form>
type 值显示成什么
text普通文本框（默认）
password密码框，输入显示成小圆点
radio单选圆圈，同组靠 name 相同来互斥
checkbox复选方框，可多选
submit提交按钮（文字跟随浏览器语言，中文环境显示「提交」）
reset重置按钮，清空表单
button普通按钮，不提交表单
file选文件
hidden隐藏字段，用户看不到但会提交
number / date / email / color / range带格式校验的专用控件
关键属性作用
name字段名，提交时以它为 key 发送，必须有
id页面内唯一标识，配合 label for 和 JS 使用
value默认值 / 按钮上的文字
placeholder灰色提示文字，一输入就消失
maxlength最多输入几个字符
size文本框宽度（按字符数，只能粗调）
required必填，不填不许提交
口诀：form 是「表单」，label 是「标签」，input 是「输入框」，button 是「按钮」，select 是「下拉」，textarea 是「大文本框」。
label for 和 input 的 id 必须一模一样，点标签才能聚焦输入框。
坑：type 值拼错浏览器不报错，会悄悄变成 text。你踩过 subbmit 的坑。

6. CSS 选择器（CSS 靠它找到元素）

选择器写法匹配谁
标签选择器div { }所有 div
class 选择器.box2 { }所有 class="box2"（可重复）
id 选择器#box1 { }id="box1"（全页唯一）
通配选择器* { }所有元素（常用于全局重置）
后代选择器.ad img { }.ad 里面的 img（你的代码用过）
直接子元素.ad > img { }只算第一层子元素
并列选择器h1, h2 { }h1 和 h2 都算
伪类a:hover { }鼠标悬停时
伪元素p::before { }在元素内部前面生成内容
口诀：点（.）是班级，井（#）是身份证，星星（*）是全体。class 可重复，id 唯一。
优先级（从高到低）：id 选择器 > class 选择器 > 标签选择器；同级时后写的赢；行内 style 最高。

7. 盒模型（最核心的 CSS 概念）

<div class="box">内容</div>

.box {
    width: 200px;      /* 内容宽度 */
    height: 100px;     /* 内容高度 */
    padding: 20px;     /* 内边距：内容与边框之间的空隙 */
    border: 5px solid black;  /* 边框 */
    margin: 30px;      /* 外边距：盒子与别的盒子的距离 */
    box-sizing: border-box;  /* 一键解决宽高被撑大的问题 */
}
口诀（从里到外）：内容 content → 内边距 padding → 边框 border → 外边距 margin。
念成 「内容 - Padding - Border - Margin」，顺序和字母缩写 CPBM 一致（由内向外）。
最常见的坑：不写 box-sizing: border-box 时，width 只算内容宽，加上 padding 和 border 会把盒子撑大。加了它，width 就是「总宽」，最省心。
全局重置写法：* { box-sizing: border-box; margin: 0; padding: 0; }

8. display 显示模式

值特点能设宽高吗
block独占一行，宽度自动撑满能
inline和文字一样排队，可换行不能（宽高无效）
inline-block既能排队又能设宽高能
flex开启弹性布局（父容器上写）能
none完全隐藏（display:none）—
口诀：block 独占一行，inline 排队站，inline-block 又排队又能量。span 是 inline，div 是 block，img 是 inline-block。

9. 定位四兄弟（你已经会用 fixed 了）

值参照谁记忆法
static（默认）不定位，老老实实按文档流排static = 静止
relative相对自己原来的位置偏移relative = 亲戚（相对于自己）
absolute相对「最近一个定位过的祖先」（找不到就相对页面）absolute = 绝对（脱离文档流）
fixed相对浏览器窗口（滚动页面也不动）fixed = 钉死（你的悬浮广告）
.ad-box {
    position: fixed;
    right: 20px;    /* 距右 */
    bottom: 50px;   /* 距下 */
    width: 120px;
    height: 120px;
    z-index: 999;   /* 层级，数字越大越靠上 */
}
口诀：静止 static、自己 relative、绝对 absolute、钉死 fixed。
方向口诀：top 上、right 右、bottom 下、left 左（顺时针）。
z-index：数字越大越靠上层（像楼层，越高越靠前）。
为什么 fixed 要写 top/right/bottom/left：fixed 元素默认会停在它原来的位置。你必须用这四个方向把它「推到」想要的位置，比如 right:20px; bottom:50px 就是「距右 20、距下 50」。

11. Flex 弹性布局（一维排列神器）

.container {
    display: flex;                /* 父容器开启弹性布局 */
    justify-content: center;      /* 主轴方向：水平 */
    align-items: center;          /* 交叉轴方向：垂直 */
    gap: 20px;                    /* 间距（新写法，好用） */
    flex-direction: row;          /* row 横排（默认） / column 竖排 */
    flex-wrap: wrap;              /* 放不下自动换行 */
}
.child { flex: 1; }               /* 均分剩余空间 */
属性管什么
justify-content主轴（左右，row 时）排列：flex-start / center / space-between / space-around
align-items交叉轴（上下）对齐：flex-start / center / stretch（默认拉伸）
gap子元素之间的间距
flex: 1平分父容器剩余空间（常用）
口诀：justify 管「前后左右」，align 管「上下高低」。
direction 是 row 就左右分，column 就上下分。

12. JavaScript 与 DOM

// 1) 找到元素
document.getElementById('box1');        // 按 id 找，返回【一个】
document.getElementsByClassName('box2'); // 按 class 找，返回【集合】
document.querySelector('.box2');         // 选第一个，返回【一个】
document.querySelectorAll('.item');      // 选全部，返回【集合】

// 2) 改内容
el.textContent = '新文字';   // 改纯文本
el.innerHTML = '<b>新内容</b>';  // 改 HTML（能塞标签）
el.style.color = 'red';     // 改行内样式
el.value = '输入框里的字';   // 改表单的值

// 3) 加事件
el.addEventListener('click', function () {
    console.log('被点了！');
});

// 4) 增删改元素
const li = document.createElement('li');
li.textContent = '新的一项';
ul.appendChild(li);   // 添加到末尾
li.remove();          // 删除

// 5) 存取本地数据
localStorage.setItem('todo', JSON.stringify(list)); // 存
const list = JSON.parse(localStorage.getItem('todo')) || []; // 取
概念一句话
DOM浏览器把 HTML 变成一棵「对象树」，JS 通过它就能改网页
变量let（可重新赋值）/ const（不可重新赋值）
函数function 名字(参数){ return 结果 }
数组[1,2,3]，常用 push/map/filter/forEach
对象{ 键: 值 }
事件用户动作：click / input / submit / keydown
口诀：getElementById 单数返回一个，getElementsByClassName 复数返回一堆。
三大能力口诀：找元素 → 改内容 → 绑事件。
你的 DOM.html 已经做对了两件事：① 用了 id / class / 普通标签三种选择器做对比；② 用 console.log 把找到的元素打印到控制台（F12 → Console）查看。以后每写一句 JS 都 console.log 一下，看得见就不会忘。

13. Git / Netlify 速查

git status              # 看现在有哪些改动
git add .               # 把改动放进暂存区
git commit -m "说明"    # 存一个版本（说明要写人话）
git push origin main    # 上传到 GitHub（必须开着 Clash！）
知识点说明
工作区 / 暂存区 / 仓库改文件 → add → commit → push，四步流水线
index.htmlNetlify 首页只认这个名字（根目录必须有它）
多页面一个网站 = 一个文件夹 + 多个 html，用 <a href="xx.html"> 串起来
坑：push 失败最常见原因是 Clash 没开（GitHub 直连不上），而且 VS Code 报错很不显眼。推之前确认：Clash 首页「系统代理」开关是亮的。

14. 自测题（先做，再看答案）

1. 盒模型里，从里到外的顺序是？padding / border / margin / content

答案：content → padding → border → margin（口诀 CPBM）。

2. position: fixed 是相对谁定位？

答案：相对浏览器窗口，滚动页面也不动。

3. 想让 input 框变宽，用哪个属性？size 还是 width？

答案：用 CSS 的 width。HTML 的 size 只能按字符数粗略调宽。

4. 单选按钮 radio 要互斥，靠什么？

答案：给同组 radio 相同的 name 属性值。

5. getElementsByClassName 返回什么？

答案：返回 HTMLCollection（集合，类似数组），取第一个要写 [0]。

6. 为什么我的 submit 按钮没显示？

答案：type 值拼错了（写成了 subbmit），浏览器静默降级成 text 输入框。

7. flex 布局里，横向排列用哪个属性居中？

答案：justify-content: center；纵向居中用 align-items: center。

8. Netlify 打开网址看到 404，最先查什么？

答案：① 仓库根目录有没有 index.html；② 代码有没有 push 上去；③ 访问的路径对不对。
